# GateLane 機制原型（2026-11-11）：分道牆、成長門、移動缺口柵欄

**狀態**：原型量測紀錄。沒有採用，沒有進正式的 sim、規格或畫面。只屬於 GateLane，不寫進共用知識庫。

**起因**：「選數字大的門＋頭目戰追頭目」一條固定規則拿到 expert 平均分的 62%、30 局擊倒頭目 28 次（見 `docs/skill_dominance_report.md` 的基準策略一節）。

## 機制（`PROTO` 的字母）

| 字母 | 機制 | 要玩家做的判斷 |
|---|---|---|
| A | 成長門 vs 定值門（等級 2、3）：一扇初值低、每射中一次加值；另一扇初值高、不能射加 | 估算火力能射幾發 |
| G | 守門怪：成長門前那群怪的血量依種子變動 | 先判斷能不能清掉 |
| B | 分道牆：交鋒、激戰、決戰各一道；在第一列選的半邊鎖到第二列，第二列的好門在另一邊；第二列門值用預告牌提前公開 | 兩列合起來算 |
| C | 移動缺口柵欄：缺口左右來回移動，隊形超出缺口的比例決定失兵 | 走位時機；兵多隊形寬更難過 |

`PROTO_HZ = 缺口半寬, 超出部分的失兵百分比, 週期（0 = 缺口不動）`。

## 結果（30 個種子；比值 = 最好的固定規則平均分 ÷ expert 平均分）

| 版本 | 最好的固定規則 | 技巧佔比 | 高手 vs 中手 |
|---|---|---|---|
| 現行 | 62.0% | 91% | 93% |
| B | 47.9%（牆前算兩列） | 84% | 93% |
| A＋B＋G | 51.9%（永遠選成長門） | 88% | 93% |
| A＋B＋G＋C，缺口不動 | 48.9%（組合口訣） | 95% | 100% |
| A＋B＋G＋C，`150,100,180` | 22.7% | 96% | 100% |
| A＋B＋G＋C，`170,50,180` | 36.9% | 95% | 87% |

`170,50,180` 的難度曲線 D1–D6 全過；柵欄碰撞率 novice 71%、intermediate 22%、expert 0%。

## 判讀

- **分道牆是唯一有效的分析型機制**：修掉 bot 偷看畫面外資訊之後，仍把比值從 62% 降到 48%。
- **成長門＋守門怪沒有增加深度**：「永遠選成長門」拿到 51.9%。
- **柵欄的作用全在缺口會動**：缺口不動時比值和沒放柵欄差不多。它加的是走位時機，不是分析。
- expert bot 撞柵欄 0 次，時機判斷是完美的，真人做不到；含柵欄的比值被低估。

## 已知問題與未做的事

- 沒有畫面：牆、預告牌、成長門的提示、柵欄與缺口都沒畫。定值門不能射加，但現行畫面會畫射擊次數的格子。
- 人性化 bot 的柵欄時機誤差（casual ±18、regular ±9、skilled ±4 tick）是假設值。
- 第一輪的量測（柵欄一碰就扣固定比例）參數沒有完整記錄，已被第二輪取代，不保留。
- 這些數字用的是現行的技巧指標。依 [技巧證據的決策](../../../../knowledge-base/decisions/2026-11-11-skill-evidence.md)，「固定規則的接近程度」之後改由人判定，沒有通過線。
- 正式採用要改：規格（gdd/05、07、11）、sim（`GAME.version` +1）、bot、畫面、golden 與報告；改規格後 N2 要重新核准。
