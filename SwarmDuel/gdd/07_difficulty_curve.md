# 07 難度曲線

- **目的**：記錄 180 秒敵潮腳本的難度設計、量測方法與調校紀錄（方法見 [knowledge-base/16](../../knowledge-base/16_difficulty-curve.md)）
- **相關系統**：02 玩法（敵潮時間表）、04 內容（敵種）、05 規格 §5、[docs/playtest_report.md](../docs/playtest_report.md)
- **狀態**：2026-11-27 補寫並調校。v1（原敵潮）D4、D6 未通過；**v2 D2–D6 全過**（`GAME.version` 2）

## 設計：腳本（v2）

曲線由 `content.js` 的 `WAVES`、`EVENTS` 固定；種子只換生成角度、敵種抽選、升級牌池與光束位置（05 §3），每個種子的難度形狀相同。

| 段落（30 秒） | 新要素（每段一件） | 生成速率（隻/秒） | 事件 |
|---|---|---|---|
| 0–30 s 暖身 | 灰仔（追擊） | 1 → 2 | — |
| 30–60 s | 探針（每 1.5 秒衝刺一次） | 2 → 2.5 | — |
| 60–90 s | 巨灰（高血量、慢） | 2.5 → 3 | — |
| 90–120 s | 包圍環（18 隻同時從四周進場，段末） | 3 → 3.5 | 115 s |
| 120–150 s | 偵察飛碟（頭目，段首）；探針加倍 | 3.5 → 3.75 | 120 s |
| 150–180 s | 母艦（HP 900）＋母艦光束（每 2.5 秒一道、預警 1 秒） | 3.75 → 4.25 | 160 s 母艦、170 s 起光束 |

最後一段有兩件新東西（母艦與光束），是收尾。

## 設計：容錯參數（v2）

| 參數 | 值 | 作用 |
|---|---|---|
| 玩家 HP | 100（`p_hp` 每級 +20） | 新手能撐多久 |
| 受傷後無敵 | 30 tick（0.5 秒） | 一次碰撞不連扣 |
| Dash | 冷卻 100 tick（1.67 秒）、前 0.2 秒無敵 | 脫困與穿怪 |
| 起手松果 | 冷卻 20 tick（每秒 3 發） | 前段清怪速度追得上出怪 |
| 熱狗 | 每 150 殺一個，回血 30 | 後段回血 |
| 同屏上限 | 300 隻 | 效能上限，超過的生成略過 |

## 量測

`node tools/playtest.mjs 30`（`npm run playtest`）：30 個種子 × 三位人性化玩家（`tools/humanBots.mjs`），報告 [docs/playtest_report.md](../docs/playtest_report.md)。

- **單位** = 10 秒，**段落** = 30 秒；暖身段不算主段落。
- **DI** = 每秒進場的敵人 HP（灰仔 = 1）。頭目與包圍環整批算在抵達的那個單位，光束每道算 2。只由腳本決定，每個種子相同。
- **命中率的對應**：生存類沒有「打中幾拍」，改量**無傷秒數比例**（活著的秒數裡沒有受傷的比例）；倒下後的單位不計。心流帶 90–99% 照 `RULE-CURVE-FLOW`。
- **人性化玩家**：決策間隔（反應時間）、近身敵人越多越容易偏一格方向（讀取負荷）、偶爾維持原方向（失神）、敵人到多近才 Dash、最後一分鐘疲勞。新手不繞圈、選第一張卡；一般、熟手繞圈並依優先序選卡。**參數是估計值，未經真人校正**。
- 人性化玩家會在光束預警圈出現時離開（真人看得到 1 秒的紅圈）；v1 量測時還沒有這條，改了之後 v1 的光束傷害會略低。
- D1（技巧主導）用舊配方，見 [docs/skill_dominance_report.md](../docs/skill_dominance_report.md)；D7、D8 只用於有節拍的品類。

## 結果

v2（30 個種子，`docs/playtest_report.md`）：

| 檢查 | 結果 | 數據 |
|---|---|---|
| D2 整體上升 | ✅ | ρ = 0.88 |
| D3 接近線性 | ✅ | R² = 0.52（門檻 0.5，餘裕小） |
| D4 鋸齒向上 | ✅ | 段落高峰 2.3 → 5.3 → 8.0 → 12.3 → 15.1 |
| D5 無斷崖 | ✅ | — |
| D6 心流帶 | ✅ | 一般玩家無傷秒數 94% / 94% / 94% / 92% / 92% |

| 玩家 | 撐完全場 | 倒下時間中位數 |
|---|---|---|
| 新手 | 47% | 179 秒 |
| 一般 | 67% | 180 秒 |
| 熟手 | 77% | 180 秒 |

D1（舊配方，`docs/skill_dominance_report.md`）：技巧佔比 82.7% → **86.1%**，高手 vs 會走位 76.7% → **90.0%**。

**穩健性**：D6 在 90% 附近、每段約有 ±3 個百分點的種子雜訊，所以調校時每個候選都用 3 組不重疊的 30 種子驗（共 90 局）。v2 三組的一般玩家平均：94.7 / 94.3 / 94.3 / 91.7 / 91.7%，三組各段都 ≥ 90%。D2–D4 只由腳本決定，不受種子影響。

## 判讀

1. **v1 的問題是起手火力追不上出怪。** 起手松果每秒最多殺約 1.25 隻灰仔，出怪一超過就越積越多（60 秒時場上 100+ 隻、玩家才 2–4 級），後段又卡在 300 隻上限，所以中段難、後段反而變鬆。只降出怪速率會讓擊殺與經驗一起變少，沒有幫助；加快起手松果才讓前段的怪清得掉。
2. **後段的傷害來自頭目與光束。** 偵察飛碟 145 秒進場時，要 15 秒才追到玩家，會拖進最後一段；改成 120 秒段首。光束原本每 50 tick 一道、緊貼玩家，是 v1 最後一段的主要傷害；改成 2.5 秒一道、預警 1 秒。
3. **一般玩家逐段變難、不回升**（94 → 94 → 94 → 92 → 92）。新手的數字因為活下來的跑次變多而上下波動（87–92%），不是曲線本身回升。
4. **目標值未達**：knowledge-base/16 的新手倒下時間中位數目標是全長的 55–80%；v2 是 179 / 180 秒（新手 47% 撐完全場），比目標好打。v1 是 87 秒（48%）。若要讓新手更早倒下，又不讓一般玩家掉出心流帶，可以考慮懲罰只在新手犯的錯（例如不 Dash 的硬碰），留待真人試玩後再定。
5. **人性化玩家未校正**：參數是估計值；有真人資料後要校正 `humanBots.mjs` 並重跑。
