# 頭目資產描述（委外重繪用）

給繪圖方的規格。第一版是程式畫的，已由這份描述的產出取代。重繪的圖放 `art/raw/boss/`。

## 第二輪方向（使用者指定，2026-11-20）

大頭目是比畫面大得多的巨艦。平常只呈現局部：艦首那一段從畫面上緣伸進來，朝下攻擊，以左右橫移為主；往前衝鋒時才露出更多艦身。所以整艘艦畫成縱長（長寬比約 1:2），核心與武裝集中在艦首，砲口與爪、臂、翼尖朝下。這一輪的提示詞全文在 `raw/boss/prompt_big.sh`，下面「共同規格」與表格是第一輪的版本，配色與造型元素仍然適用，構圖以本節為準。

## 共同規格

| 項目 | 規格 |
|---|---|
| 視角 | 正俯視（從正上方往下看），艦首朝畫面下方（朝向玩家），左右對稱 |
| 風格 | 16-bit 街機射擊遊戲的像素畫。硬邊像素、有限色盤（每艘 12 到 16 色）、深色描邊、左上受光右下陰影、面板線與鉚釘。不要平滑漸層、不要反鋸齒、不要光暈 |
| 對齊主角機 | 與 `art/raw/ship_heavy.jpg` 同一套筆觸與細節密度（機甲式外掛裝甲、推進莢艙、感測燈） |
| 題材 | 是戰艦，不是人物。只用該神祇在古典圖像裡的特徵物當造型元素。不畫人臉、人體、宗教符號、文字 |
| 背景 | 純色 #00ff00，沒有陰影、沒有地面、沒有特效，方便去背 |
| 一張圖的內容 | 同一艘艦的三個階段由左到右並排，等比例、中心對齊、彼此不重疊 |
| 階段一：外甲 | 完整的艦體，裝甲板齊全，砲管與燈點都在 |
| 階段二：骨架 | 外甲（翼、螯、臂等外掛部分）被打掉，露出同色系的桁架與管線；艦身留著，有彈孔、焦痕、餘燼 |
| 階段三：核心 | 只剩核心與周圍一小塊撕裂的艦身，寬度約為階段一的六成，邊緣是燒紅的金屬，核心發亮 |
| 遊戲內大小 | 見各艦。畫的時候每艘階段一約 256 像素寬的美術像素即可，之後縮成遊戲用的格數 |

## 交回的格式

- 頭目：每艘一張 PNG，三個階段並排。檔名 `big_oceanus.png`、`big_nyx.png`、`big_eos.png`、`big_atlas.png`。
- 小王：四艘並排一張，`mids.png`。
- 進遊戲前由 `art/tools/` 的工具去背、縮成遊戲格數、轉成色盤資料。
