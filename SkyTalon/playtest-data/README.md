# 試玩紀錄

## 怎麼收

1. 請試玩者開 `http://<這台電腦的位址>:5178/?playtest=1&tester=<代號>`（代號用英數或中文，不要用真實姓名）。
2. 不要先講解規則，讓他看開始畫面自己玩；至少玩 3 局，可以按「同一題再飛」或「換一題」。
3. 結算面板按「匯出試玩紀錄」，會下載 `skytalon-playtest-<代號>-<日期>.json`。
4. 把檔案放進這個資料夾的根目錄。

紀錄只存在試玩者的裝置上，遊戲不連線、不上傳。每一筆是一局的種子、輸入紀錄與分數，加上代號、時間與螢幕尺寸；沒有其他個人資料。

## 怎麼看

在 `SkyTalon/game` 執行：

```
npm run human-report
```

報告寫到 `SkyTalon/docs/human_playtest_report.md`：每一局先重播驗分，再逐段和模擬玩家（`game/tools/humanBots.mjs`）對照擊破率、被打中次數、存活率。

## 試玩時順便記下來的事（報告量不到）

- 看完開始畫面，知不知道要做什麼、分數怎麼來。
- 手指有沒有遮住機體或子彈。
- 哪一種敵機第一次出現時看不懂。
- 被打中時知不知道是被什麼打中的。
- 覺得太簡單還是太難，在哪一段。
