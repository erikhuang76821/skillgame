## 1. 難度級（每級只加一件事）

| 級 | 新要素 | 玩家要學的 | 登場單位 |
|---|---|---|---|
| L1 | 直落機：直線下來、不開火 | 左右對位 | 0 |
| L2 | 砲艇：停在上方，定時朝玩家開一發 | 一邊打一邊橫移閃瞄準彈；先打會開火的 | 2 |
| L3 | 蛇行機：左右擺動，往下射三發散彈 | 預判擺動、從散彈縫隙穿過 | 7 |
| L4 | 俯衝機：預告 1 秒後朝玩家位置衝下來 | 預告時打掉，或看準後側移 | 14 |
| L5 | 頭目：環形彈加瞄準三連發 | 在彈幕裡維持對位 | 19 |

新要素登場的那個單位只放 1 架（蛇行機、俯衝機、砲艇都是從 1 架開始）。

## 2. 腳本表

單位 = 4 秒。數量 =〔直落、砲艇、蛇行、俯衝〕。種子只決定每架的航道與同一單位內的進場順序。
v2：進場數量與 v1 相同；後段敵機另外加血（`SECTION_HP`：上升 +1、加速與調息 +2、高潮 +3），下表的 DI 已含加血。選卡在單位 2、7、12、19 開始時。

| 段落 | 單位 | 主段落 | 每單位數量 | DI 平均／高峰 |
|---|---|---|---|---|
| 暖身（安全） | 0–1 | | 2,0,0,0 → 3,0,0,0 | 0.21 / 0.25 |
| 上升 | 2–6 | ✓ | 3,1 → 4,1 → 4,2 → 5,2 → 5,3 | 1.95 / 3.00 |
| 加速 | 7–11 | ✓ | 4,1,1 → 4,2,2 → 4,2,2 → 5,2,3 → 5,2,3 | 3.88 / 4.75 |
| 調息（安全） | 12–13 | | 3,0 → 3,1 | 0.92 / 1.33 |
| 高潮 | 14–18 | ✓ | 4,2,2,1 → 4,2,2,2 → 4,2,3,2 → 5,2,3,2 → 5,3,3,3 | 7.32 / 9.67 |
| 頭目 | 19–23 | | 頭目獨占 | 3.00 |

- 每個主段落開頭的 DI 比上一段高峰低（加速 2.25 < 上升高峰 3.00；高潮開頭 5.38 略高於加速高峰 4.75，中間有調息）。
- 「安全」指負荷低，不是不會受傷；本作沒有無敵段。
- 頭目只有一個目標，不能逐單位量擊破率，所以不列為主段落；另外報告擊破率與倒下時間。

**DI 定義**（`tools/playtest.mjs`）：擊破該單位敵機所需的對位開火時間佔該單位的比例 × 4，加上 0.5 ×（砲艇 + 蛇行機）、1 × 俯衝機。前項是「要打多久」，後項是「會被打多少」。v2 的 DI 用基本火力（間隔 5 tick）算：加血是腳本的要求，火力卡是玩家的回應，所以不算進 DI。

## 3. 容錯參數

| 參數 | 值 | 作用 |
|---|---|---|
| 護盾 | 3 格；v2 可用加厚護盾加格、擦彈充能回復 | 決定新手能撐多久 |
| 無敵時間 | 90 tick（1.5 秒） | 一次失誤不會連帶再中一發 |
| 被彈判定半徑 | 9 px（機身約 40 px 寬） | 判定比外觀小，擦身而過不算中 |
| 俯衝預告 | 60 tick（1 秒） | 大於新手反應時間 320 ms |
| 砲艇開火間隔 | 70 tick | 兩發之間有時間橫移 |

## 4. 人性化試玩模型

`tools/humanBots.mjs`，三位玩家共用同一個走位規劃器，差別在人的限制：

| 玩家 | 反應（幾 tick 決定一次） | 往前看 | 瞄準誤差 | 恍神 | 一分鐘後的疲勞 |
|---|---|---|---|---|---|
| 新手 casual | 19（約 320 ms） | 30 tick | ±34 px | 6% | 誤差 +30% |
| 一般 regular | 15（250 ms） | 36 tick | ±20 px | 2% | +15% |
| 熟手 skilled | 12（200 ms） | 42 tick | ±10 px | 0.5% | +5% |

選卡（v2）：三位各有一張固定的優先表，從三張裡拿排最前面的那張。

| 玩家 | 想要的順序 |
|---|---|
| 新手 | 火力三張（連射、散射、穿透）優先，每次都拿火力 |
| 一般 | 連射 → 加厚護盾 → 散射 → 連鎖上限 → 穿透 → 其餘 |
| 熟手 | 連鎖上限 → 連射 → 擦彈加分 → 穿透 → 近身擊破 → 其餘 |

反應時間取自 [16 §3.1](../../knowledge-base/16_difficulty-curve.md)，其餘是起手值，要等真人資料（N9）校正。沒有模擬「第一次看到新敵機」的學習效應。

- 全火力的分數範圍很窄（9178–9421），全得分很寬（9838–11662）：得分卡是高風險高報酬。

## 8. 已知弱點

1. **防禦軸偏弱**。對幾乎不被打中的玩家沒有用；模擬的新手也只被打中 0.6 次，看不出防禦卡的價值。要等真人資料（真人被打中的次數會多很多）才能判斷要不要加強。
2. **三位模擬玩家幾乎不被打中，而且全部活到最後、全部擊破頭目**。規劃器對敵彈的預測是精確的直線外推，真人做不到這麼準；v2 有了卡片之後更輕鬆。存活率偏樂觀，要等 N9 校正。
3. **頭目段的難度沒有進曲線檢查**，只有擊破率可看。頭目血量沒有跟著加，拿了火力卡之後偏快倒。
4. **上升與加速段 98% 仍靠近心流帶上緣**（上限 99%）。
5. **熟手擊破率 82% 落在心流帶之外**。規則只檢查一般玩家，所以不算未通過；但這表示得分卡的代價不小，真人熟手可能覺得後段打不完。

### 9.5 技巧證據（調校批次 30 題，不是確認批次）

強策略對五條比較策略都是 30 勝 0 敗。簡單策略的平均分佔強策略的比例：追最近敵機＋火力 11.8%、左右掃 8.8%、追最近敵機＋防禦 7.4%、原地不動 0.3%。v3 單章時最接近是 39.9%：局拉長之後，不躲子彈的打法全部停在第一章，差距拉大。確認批次（第 3 批）要由人下指令。
