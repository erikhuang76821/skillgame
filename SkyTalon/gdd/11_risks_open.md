# 11 風險與待決

## 風險

| # | 風險 | 影響 | 對策 |
|---|---|---|---|
| R1 | 「只追最近敵機、不躲子彈」就能拿到接近高手的分數 | `RULE-SKILL-BEATS-SIMPLE` 不過、技巧天花板低（[01 §4](../../knowledge-base/01_skill-integrity.md) GateLane 教訓） | 連鎖歸零與有限護盾讓不躲彈付出代價；N5 量測，不夠就回本規格改機制（例如砲艇彈更密），不改門檻 |
| R2 | 連鎖加分放大單次失誤的影響，讓結果看起來像運氣 | 技巧證據變弱（[12 §3](../../knowledge-base/12_genre-recipes.md)） | 連鎖是加法且封頂 20；N5 先把 `CHAIN_STEP` 設 0 跑一次對照 |
| R3 | 擦彈鼓勵貼彈，新手覺得被引誘去送死 | 新手挫折 | 擦彈每顆只 2 分，是高手的加分項而不是主要分數；開始畫面說明 |

| R5 | 一般玩家的擊破率落不到心流帶，或段落間有斷崖 | `RULE-CURVE-FLOW`／`RULE-CURVE-CLIFF` 不過 | N5 用人性化試玩逐單位調 §5 的數量表；新要素登場的單位數量先少 |

| R10 | Pixi 8 自訂 shader 的 API 與記憶不符 | 畫面出不來 | 寫之前對照 `node_modules/pixi.js` 的型別與原始碼 |
| R11 | 局長 96 秒在台灣 2–5 分鐘基準的下緣 | 偏短 | 先以 96 秒驗證曲線；要加長就加段落，不拉長現有段落 |

| R13 | 火力變強後擊破率超出心流帶上緣（v1 上升段已在 99%） | `RULE-CURVE-FLOW` 不過 | N5 以三種人性化玩家各自的選卡方式重調進場表；v1 的調校紀錄不再適用 |
| R14 | 選卡暫停打斷節奏與第一期做的速度感 | 手感變差 | 選卡放在段落交界（本來就是換氣點）；選完倒數約 1 秒再恢復；捲動速度與風聲在選卡時降下、恢復時拉回。v3：量到第 3、4 次選卡開在彈幕中，改成選卡清掉機體周圍 200 像素內的敵彈加 0.75 秒無敵（05 §8） |

| R15 | 本期每張卡最多出現兩次，疊層深度有限 | 構築變化偏少 | 先驗證有沒有取捨；第三期局長拉長後增加選卡次數與等級上限 |
| R16 | 玩家子彈變多（最多約 140 發），畫面變亂、敵彈看不清 | 公平視野（E3） | 斜射彈與穿透彈壓低亮度，敵彈仍是畫面上對比最高的東西；N6 用滿級畫面驗收 |
