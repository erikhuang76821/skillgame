## 1. 每個系統的三問

| 系統 | 有沒有玩家控制不了、但會影響分數的東西？ | 條件是否完全相同？ | 能不能拿出證據？ |
|---|---|---|---|
| 敵機進場 | 沒有。每 4 秒一個單位，各單位的敵機種類與數量是固定腳本；種子只決定航道與單位內的進場順序 | 同種子相同；玩家怎麼飛都不會改變進場表 | 重播；測試比對兩種飛法下的進場表 |
| 敵機行為 | 沒有隨機偏移。直落、定點瞄準射擊、蛇行、俯衝各有固定規則；瞄準與俯衝鎖定的是玩家當下位置（玩家可控） | 相同 | 重播 |
| 頭目彈幕 | 環形彈的起始角由種子與「第幾圈」決定；瞄準彈朝玩家 | 相同 | 重播 |
| 玩家火力 | 自動開火、固定傷害；無暴擊。間隔與彈道只會被玩家自己選的裝備與拾取的掉落物改變 | 相同 | 重播 |
| 選卡（v2） | 沒有。三張卡照每軸固定順序輪替，種子只決定起點；選卡時機是固定 tick；玩家選什麼不影響之後出現的卡。選卡期間時間暫停，想多久都不影響分數。v3：選完清掉機體周圍的敵彈並短暫無敵，對所有人、所有卡都一樣，只看固定的選卡時機 | 同種子所有人每次看到同樣三張卡 | 選卡紀錄（tick、序號、選項）隨重播上傳；測試比對兩種選法下之後的選項 |
| 受擊 | 固定 3 點生命、固定無敵時間；無機率閃避。v6 的護盾裝備是「擋一次、固定時間重建」，不是機率 | 相同 | 重播 |
| 計分 | 只來自擊破、擦彈、頭目擊破的剩餘時間、結束時的護盾 | 相同 | 結算逐項列出；理論上限可算 |
| 輸入 | 每 tick 取樣一次方向，固定 60 Hz；幀率不影響 | 相同 | 輸入紀錄逐 byte 上傳 |

## 2. 去隨機化對照

一般捲軸射擊常見的隨機，本作的做法：

| 隨機來源 | 一般做法 | 本作 |
|---|---|---|
| 敵機生成 | 依時間隨機出怪、動態難度 | 固定腳本；第 *i* 架的航道 = `rng(seed, 'lane', i)`，第 *k* 單位的順序 = `rng.shuffle(seed, 'order', k)` |
| 道具、火力升級 | 機率掉落 | v6 有掉落物，擊破敵機後掉出。但哪一架帶貨、帶什麼，在開局時由種子寫進進場表，是題目的一部分；擊破的那一刻不擲骰。頭目被擊破必掉一個裝備升級（不是機率）。「裝備升級給哪一件」由種子與第幾次升級決定，只有可選範圍取決於玩家持有的裝備。沒有任何骰子是在玩家行動之後才擲的 |
| 山峰、隕石（v6） | 隨機出現的地形 | 障礙物表在開局時由種子排定，進場前有預告；頭目戰期間不出現 |
| 選擇（v7） | 抽卡 | 補給的三件裝備只由種子與第幾次補給決定；選擇時時間暫停，想多久都不影響分數。小王或頭目沒被擊破就沒有那次補給，但之後各次的內容不變 |
| 裝備與分數（v6） | 強化直接加分、加倍率 | 裝備、三選一、掉落物都不給分，也不改計分參數。回血換不到分數：結束加分看的是被打中幾次，不是剩幾點生命；護盾擋下的也算一次 |
| 機體改裝（v4） | 隨機出現的強化 | 三個選項固定、所有人相同、不看種子，只在打完頭目一、二之後各選一次 |
| 彈牆缺口、螺旋彈、水雷（v4） | 每次隨機 | 缺口位置只看種子與彈牆序號，發射前有預告；螺旋彈角度固定前進；水雷固定時間引爆。玩家怎麼飛都不會改變這些 |
| 追獵體、光柱（v5） | 隨機亂飛、隨機落點 | 追獵體只朝玩家當下位置轉向（玩家可控）；光柱位置在預告時固定，之後不動。兩者都不用隨機 |
| 章節長度（v4） | — | 頭目早倒就直接進下一章，快慢取決於玩家；進場表與選卡時機都跟著腳本時鐘走，同種子所有人遇到的內容與順序相同 |
| 升級三選一 | 每次從卡池隨機抽三張 | 每軸三張卡固定輪替，起點 = `rng(seed, 'offer', 軸)`；每張卡在前三次一定各出現一次，輪替順序公開，可以預先規劃 |
| 暴擊、傷害浮動 | 機率 | 取消；每發固定 1 點 |
| 敵彈散佈 | 隨機角度 | 瞄準彈朝玩家；散彈角度固定；頭目環形彈起始角 = `rng(seed, 'boss', 第幾圈)` |
| 敵機 AI | 隨機偏移、隨機開火 | 開火時機只看該機進場後的 tick 數 |
| 局外加成 | 養成、復活、分數倍率 | 全部沒有 |

RNG 一律用無狀態雜湊，index 是事件序號（第幾架、第幾單位、第幾圈），不是呼叫次數。

## 3. 技巧來源（高手比中手多拿分的地方）

1. **走位瞄準**：火力只往正前方，要對準敵機才打得到。定點射擊機血厚又會開火，先打誰、何時離開去清直落機，決定擊破數。
2. **閃避不斷鏈**：連續擊破不被打中，每架的加分逐步增加到上限；被打中歸零。高手整局維持高連鎖。
3. **擦彈（風險換報酬）**：敵彈擦身而過加分，每顆只算一次。貼得越近越危險，是高手和「只會躲」的差別。
4. **頭目速殺**：頭目倒下時依剩餘時間加分；要在彈幕裡維持對位才打得快。
5. **構築規劃（v2）**：四次選卡。火力卡誰拿都有用；得分卡與擦彈充能要貼彈、靠近、不斷鏈才換得到分，只有打得好的人值得拿。輪替順序公開，高手會為了進化預留選擇。

## 4. 已知風險與對策

| 風險 | 來源 | 對策 |
|---|---|---|
| 「活著就有分」讓逃跑型玩法接近高手 | [01 §4](../../knowledge-base/01_skill-integrity.md) SwarmDuel R9 教訓 | 沒有存活秒數分；結束護盾分只佔小比例；N5 用簡單策略（原地不動、左右來回、只追最近敵機不躲彈）對照 |
| 一條簡單規則就能玩好 | 同上 GateLane N2 教訓 | 連鎖與擦彈讓「只追敵機不躲彈」付出代價；N5 由 `RULE-SKILL-BEATS-SIMPLE` 擋 |
| 擦彈在無敵時間內可無風險刷分 | 本作設計 | 無敵期間不計擦彈 |
| 觸控與鍵盤操作差異 | [13 §1](../../knowledge-base/13_input-fairness.md) | 兩者都量化成同一組 8 向加停止；移動速度固定，沒有類比量 |
| 選卡變成運氣（這局剛好出現好卡） | [af-survivor-skill-pick](../../knowledge-base/ad-funnel/af-survivor-skill-pick.md)「隨機 / 選擇噱頭」 | 不抽卡，改固定輪替；同種子所有人選項相同；排行只比同種子 |
| 有一種固定選法永遠最好，選卡沒有取捨 | 本作設計 | N5 報告列出四種固定選法的平均分；某一種在所有種子都最好就回規格改卡 |
| 火力卡讓「不躲彈只追敵機」也能拿高分 | 同 R1（[11](11_risks_open.md)） | 簡單策略都配「一律選火力」再量一次，由 `RULE-SKILL-BEATS-SIMPLE` 擋 |
| 巨集或輔助程式 | [13 §4](../../knowledge-base/13_input-fairness.md) | 伺服器重播驗分；輸入紀錄留給風控，門檻待真人資料 |
| 跨引擎結果不同 | [04 §4](../../knowledge-base/04_tech-stack.md) | 位置用整數子像素、方向查表、距離比平方；固定種子的 golden match 測試 |
