# 11 風險與待決

## 風險

| # | 風險 | 影響 | 對策 |
|---|---|---|---|
| R1 | 一直跳斬（`jumper`）或一直抓投（`grabber`）就能過，清版類的老問題 | `RULE-SKILL-BEATS-SIMPLE` 不過；讀光色不再重要 | 跳斬落地硬直、精英與頭目的對空招、抓不住大型敵人與起手中的敵人；N5 量兩條簡單策略，不過就回本規格改（例如加長落地硬直、增加對空招），不改門檻 |
| R2 | 「見起手就閃」太強，光色沒有意義 | 讀招不是技巧軸 | 閃避耗體力、完美閃避窗口窄；金光蓄滿後的強招範圍大、閃避距離不夠就吃；N5 `dodger` 對照 |
| R3 | 卸勁窗口 8 tick 對手機觸控太嚴 | 新手挫折、觸控吃虧 | N9 依裝置分開看卸勁成功率；窗口可調，但所有裝置同值（不做裝置補償以外的放寬）；需要時加延遲校正（[13 §3](../../knowledge-base/13_input-fairness.md)） |
| R4 | 只用滑鼠的玩家走位與出招不能同時做；深度軸對位更需要細走位 | 電腦滑鼠玩家吃虧 | 點地面移動在按按鈕時不中斷（目標點保留）；N9 依裝置分開看；差太多就改操作設計，不改計分 |
| R5 | 某個流派或技能配點永遠最好 | 流派與技能樹沒有取捨 | N5 三流派對照；照 [17 §2](../../knowledge-base/17_design-principles.md)「平衡不等於平均」：保留長處，改硬直、判定、發動時間，不先砍威力 |
| R6 | 兩側包夾＋同一條線上的攻擊，玩家被夾在中間無解 | 一定會扣血（`RULE-NO-FORCED-HIT` 精神） | 同時進攻 ≤ 2、同側 ≤ 1；閃避可以斜向離開這條線；N4 測試：兩人一左一右同時出招時至少有一種輸入完全不受傷 |
| R7 | 前景遮擋件或背景顏色蓋住起手光色 | 公平視野（E3） | 前景件只放在地面帶以外或半透明；光色描邊畫在最上層；背景色避開白、金、赤（gdd/02 保留色） |
| R8 | 美術量：側視角色需要的姿勢比俯視多（跳躍、被抓、被摔），加上五關背景與障礙物 | N6 時程 | 程式骨架共用姿勢；背景每關兩層、可水平接縫；障礙物 4 種＋補給 2 種同一張 atlas；分期見待決 2 |
| R9 | 局長 4–6 分鐘偏長；選路讓兩條路的局長不同 | 重玩意願、排行可比性 | 排行只比同一題；N5 用人性化 bot 量兩條路各自的局長與分數，兩條路的最佳分數差距要小於熟手的題目間差距 |
| R10 | 劍塚面板操作多，劍塚變成主要停留時間 | 節奏變慢 | 面板時間不計入局長，但真人會覺得慢；面板一頁完成、常用操作（升級、點節點）一鍵；N9 問感受 |
| R11 | 敵人 AI 規則多（進場、對位、包夾、讓位、對空），確定性難驗 | 重播不一致 | 每條規則有單元測試；golden match；實體依 id 處理 |
| R12 | 暗黑仙俠題材碰到台灣禁忌（神明、廟宇、法器） | `RULE-ART-TW-TABOO` 不過 | 世界觀用虛構仙門；不畫佛寺、僧人、道觀、符籙；N6 每張圖人工驗收 |
| R13 | 參考作太像 | 侵權疑慮 | 天刀手遊、鹽與聖所、三國戰記、街頭快打只借**品類結構**（讀招、卷軸鎖定、深度軸、抓投、破壞物）；名稱、招式名、角色、畫面、音樂、關卡全部原創 |
| R14 | 倒下整關重來，關卡後段倒下很挫折 | 新手放棄 | 每關只有 3–4 個戰區、約 1 分鐘；頭目關只有一個戰區；倒下不扣分；N5 看新手模型的倒下次數與完成率，N9 問真人感受 |
| R15 | 輸入 byte 已用滿，之後要加子 tick 相位或更多動作會放不下 | 擴充困難 | 動作碼還有 5 個保留值；真的需要子 tick 時改成 `Uint16Array`，在 §0 註明並 `version` +1 |

## 待決

| # | 題目 | 選項 | 什麼時候決定 |
|---|---|---|---|
| 1 | 遊戲名稱 | 「燼仙錄」「斬厄」「墮仙夜行」或另給；查重 | N10 前（id 跟著定） |
| 2 | 第一版做多少內容 | v5（2026-11-26 決定）：劍流派為主（刀、槍照舊由掉落與寶箱取得）＋ §5.14 的五關與一次選路；崖下屍將、鬼面石室屬後續章節 | 已決定 |
| 3 | 卸勁窗口要不要延遲校正 | 窗口 8 tick（133 ms）比節奏遊戲寬，預設不校正；N9 觸控成功率明顯偏低再加 | N9 |
| 4 | 各關實際長度與戰區數 | §5.14 是起手值；主線 4–6 分鐘是目標 | N5 用人性化 bot 量 |
| 5 | 頭目是否可以重試而不回劍塚 | v5：頭目關的劍塚就在門外，倒下回門外重打 | 已決定 |
