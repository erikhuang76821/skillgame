## 1. 風格

| 項目 | 設定 |
|---|---|
| 名稱 | 墨青像素（原創） |
| 視角 | v5 起為**橫向卷軸側視**：地面帶 3/4 斜俯（角色骨架仍用地面壓扁 0.6 的投影），背景分遠景（視差）與近景（牆帶＋地面帶）兩層；鏡頭只橫移、不旋轉 |
| 筆觸 | 16-bit 像素、大方塊、無反鋸齒、無漸層；1 px 深靛外框（不用純黑）；左上光源；每材質 3 階 |
| 色彩 | 墨灰、青黛為底，低彩度；陣營靠布料色區分：玩家靛青、屍傀暗赭、蠱系苔綠；頭目在同色系內加深、加一個點綴色 |
| 保留色 | **金、赤、白**只給敵人讀條光（`FEEL.colors.gold / red / white`）、卸勁火花、命中白閃。美術裡這三色不得成片出現，金屬一律偏冷灰 |
| 可讀性 | 敵人在暗地面上要靠輪廓與布料色看得出來；縮到實際大小（1 art px = 1 world px，畫面 ×2–3）驗收 |

### 1.1 調色盤（共用，`game/src/assets/pixel/palette.json`）

固定 token，生成 prompt 與量化都鎖住；其餘色由打包工具從全部分件量化取得，總數 ≤ 32 色。

| token | 值 | 用途 |
|---|---|---|
| `outline` | #161a26 | 外框（調色盤第 0 格） |
| `ink-0` / `ink-1` / `ink-2` | #22262e / #353a44 / #4c525c | 石、陰影布、頭髮 |
| `steel-hi` / `steel` / `steel-lo` | #b8c2cc / #7c8894 / #4e5866 | 劍身、甲片（偏冷，不與金色相近） |
| `indigo-hi` / `indigo` / `indigo-lo` | #6fb4c8 / #3f7f99 / #26506a | 玩家衣（沿用 N7 的 `PLAYER_COLOR`） |
| `ochre-hi` / `ochre` / `ochre-lo` | #a89a7c / #7d6f56 / #52483a | 屍兵、屍傀系布與皮 |
| `moss-hi` / `moss` / `moss-lo` | #8fb069 / #5f7d48 / #3b5030 | 蠱蟲、蠱師、蠱母 |
| `skin` / `skin-lo` | #c9b48f / #8f7a5e | 皮膚（屍系改用 `ochre-lo` 偏灰） |
| `lilac` / `lilac-lo` | #9c86c0 / #5e4f7c | 墮仙點綴（衣帶、殘光）；不做金色光環 |

## 2. 像素契約

| 項目 | 規格 |
|---|---|
| 比例 | 1 art px = 1 world px；`scaleMode: 'nearest'`、`roundPixels` |
| 錨點 | 分件：關節處（寫在 atlas JSON 的 `anchor`）；道具：底部中央 |
| 方向 | 頭、軀幹只畫 **正、側、背** 三向；左側由程式水平鏡像，斜向取最近的一向 |
| 旋轉 | 像素圖不即時旋轉（會鋸齒）。武器由打包工具預先旋轉成 **16 個角度**（RotSprite 類演算法，最近鄰），執行期取最近角度 |
| 四肢 | 手臂、腿維持程式繪製的線段（布料色＋1 px 外框），不出圖——它們一直在轉，像素圖只會更糟 |
| Alpha | 二值（PNG-8 單一透明索引），沒有半透明 |
| 不畫進圖 | 陰影、白閃、讀條光暈、預警圖形、刀光拖尾：程式處理（N7 已做） |
| 一致性 | 同一角色三向的頸點、腰點像素位置一致，換向不跳 |

|---|---|---|---|

### 3.2 場景（v5 橫向卷軸）

| 資產 | 尺寸（art px） | 來源 | 備註 |
|---|---|---|---|
| 遠景 ×6 關 | 450 × 150 | `far_<關>_t1.png` 整張縮小 | 視差 0.45；底部五分之一是暗色剪影，接在牆帶後面 |
| 近景 ×6 關 | 545–973 × 154（牆帶 34＋地面 120） | `near_<關>_t1.png` 依 `NEAR_CUT` 裁出牆帶與地面 | 地面帶對齊 sim 的深度帶（畫面 y 150–246）＋前緣 24 px |
| 障礙物與補給 | 酒罈 19、木箱 16、石燈 30、斷碑 30、肉包 9、丹藥 12、鍛材 9（高） | `props_v5_t1.png` 去背切件 | 底部中央錨點；sim 的碰撞尺寸見 gdd/05 §5.18，圖比碰撞框高（有高度） |

- 背景條在遊戲內每隔一份水平鏡像拼接，接縫一定對齊。
- 每關背景兩張、道具一張共用；同畫面最多 3 張貼圖＋角色 atlas，Pixi 同批（≤ 16 張）不增加 Draw Call（N8 實測）。
- 保留色：背景不得出現金、亮紅、大片白；過亮的地面（墮仙台）在遊戲內加乘色壓暗。

## 4. 生成與打包流程

照 [06 §2](../../knowledge-base/06_art-pipeline.md) 精簡：

1. **身分參考圖**：每個角色一張「正、側、背」三姿勢的大圖（全身含武器），驗收身分與配色。
2. **分件圖**：以身分圖為附圖，生成「真低解析度」的頭、軀幹三向與武器（一張圖橫排，背景透明，無文字、無陰影）。
3. **機械處理**（`art/tools/`）：切件 → Lanczos 縮到 §3 尺寸 → 硬映射 §1.1 調色盤 → alpha 二值化 → 補 1 px 外框 → 武器預旋轉 16 角 → 打包 `game/src/assets/pixel/actors.png/json`（單一 atlas）。
4. **版本紀錄**：prompt 生成前凍結到 `art/prompts/_history/`，`art/raw/LOG.md` 記錄每次生成的取捨。
5. **登錄**：`art/manifest.json` 列出所有檔案（`RULE-ASSET-REGISTER`）。
6. **驗收**：`art/preview/*_x6.png` 放大總覽＋遊戲內實際大小截圖；每張依 §5 檢核。

prompt 共用風格段落：16-bit pixel art, 1 px dark indigo outline, 3 shades per material, top-left light, TRUE LOW-RESOLUTION blocky pixels, transparent background, no text, no ground, no shadow, original design（不得使用既有 IP）。

## 5. 驗收清單（每張圖）

- [ ] `RULE-ART-TW-TABOO`：無綠色頭飾；無大面積純白／純黑；無紅金大面積；無錢幣、骰子、轉盤、「倍」「爆分」；無神明、神像、廟宇、法器（香爐、符紙、八卦、牌位）、招財貓
- [ ] 保留色：金、赤、白沒有成片出現（讀條光仍是畫面上最醒目的東西）
- [ ] 三向的頸點、腰點對齊；鏡像後劍仍在右手（鏡像時武器手換邊由骨架處理）
- [ ] 實際大小下看得出是哪種敵人（輪廓＋布料色）
- [ ] 無文字、真透明、無半透明殘邊

## 7. 對程式的影響（render 層，sim 不動）

| 檔案 | 變動 |
|---|---|
| `render/rig.js` | 頭、軀幹、武器改用 atlas 分件（依面向選正／側／背與鏡像；武器取最近角度）；四肢仍是線段但改布料色＋外框 |
