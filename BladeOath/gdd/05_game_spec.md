## §2 輸入編碼（每 tick 1 byte）

| bit | 名稱 | 觸控 | 鍵盤 | 只用滑鼠 | 說明 |
|---|---|---|---|---|---|
| 0–2 | 方向 | 浮動搖桿量化 8 向 | `WASD`／方向鍵（上下 = 深度軸進出） | 點地面：每 tick 取「玩家 → 目標點」量化成 8 向，到達後停 | 0–7 = `DX/DY[code]` |
| 3 | `IN_MOVE` | 搖桿推出死區 | 有按方向鍵 | 尚未到達目標點 | 0 = 不移動 |
| 4–7 | 動作碼 | 右下按鈕 | 見下 | 點虛擬按鈕 | 同一 tick 只送一個；多的排到下一 tick |

| 動作碼 | 名稱 | 鍵盤 | 說明 |
|---|---|---|---|
| 0 | 無 | | |
| 1 | `ACT_ATTACK` | `K` | 普攻 |
| 2 | `ACT_BLOCK` | `L` | 格擋 |
| 3 | `ACT_DODGE` | `Shift` | 閃避（往移動方向，可斜向進出深度；沒有移動就往面向的反方向） |
| 4–7 | `ACT_SKILL1`–`ACT_SKILL4` | `U` `I` `O` `P` | 招式 1–4 |
| 8 | `ACT_ESCAPE` | `Q` | 脫離 |
| 9 | `ACT_INTERACT` | `E` | 互動：劍塚、寶箱（按鈕只在附近時出現）。補給走過去自動撿 |
| 10 | `ACT_JUMP` | `Space` | 跳躍（往起跳當下的移動方向）；在空中再按攻擊鍵就是空中攻擊（§5.16） |
| 11–15 | 保留 | | |

配置原則（2026-11-27 使用者決定）：左手 WASD 移動、Space 跳、Shift 閃（閃的方向就是左手正在按的方向）、Q 脫離、E 互動；右手 K 攻、L 擋，四招在上排 U I O P（U、I 是開局兩招能「斷」的招）。觸控按鈕以「攻」為中心排成拇指弧：內圈擋、閃、跳，外圈四招，脫離最小最遠。

抓取沒有按鍵：貼著小兵、朝它推方向（§5.17）。v4 的 `ACT_RETARGET`（切換鎖定）拿掉：面向只有左右，攻擊打的是同一條線上、面前的敵人。

- 輸入走 `InputClock`／`TapQueue`：以事件時間戳歸到所屬 tick（[13 §1](../../knowledge-base/13_input-fairness.md)）。按鈕按下是一次動作；**按住不重複送**（格擋是冷卻制，不需要按住）。
- 「只用滑鼠」的點地面移動在 render 層換成方向位元後才進紀錄，所以重播只看位元，跟游標位置無關。
- 動作碼在「不能動的狀態」（硬直、收招中）送出時：在 `BUFFER_TICKS` = 8 內排隊，狀態結束時生效；超過就丟掉。脫離不排隊，硬直中直接生效。
- 戰鬥中的暫停在 render 層（停止推進 tick），不進 sim；畫面遮住，每局最多 `PAUSE_MAX` = 3 次（記進 `rec.meta`）。

## §3 隨機來源

| stream | id | 用途 | index 意義 | 範圍 / 分布 |
|---|---|---|---|---|
| `spawn` | 1 | 每個戰區把同難度級的小兵池排到該戰區的配置點 | 戰區序號（全章連號） | `rng.shuffle(seed, 'spawn', 戰區, POOL[戰區])` |
| `combo` | 2 | 敵人第 *k* 輪的出招順序（只在該敵人難度級的招式池內） | `敵人配置點 × 64 + k` | `rng.shuffle` 招式池 |
| `enter` | 3 | 小兵從左或右進場、進場延遲（同一戰區內錯開） | 配置點序號 | 側：`rng.int(..., 2)`；延遲：`rng.int(..., ENTER_SPREAD)`，`ENTER_SPREAD` = 90 tick |
| `look` | 4 | 小兵外觀變體（只給畫面） | 配置點序號 | 0–3 |

規則：index 是配置點或戰區序號，**不是**生成次數；倒下後重來的關卡用同一組 index，所以敵人種類、進場側與延遲都和第一次一樣。關卡骨架、障礙物、破壞物與它的掉落、精英、頭目、寶箱都不用 stream。

## §4 Tick 順序

```
1. 清空 events；若 phase = choice（劍塚面板）直接返回
2. 解碼輸入；動作碼進緩衝（BUFFER_TICKS）
3. 玩家：狀態推進 → 可行動時取緩衝動作 → 抓取判定（§5.17）→ 移動、跳躍與障礙物碰撞；夾在鏡頭左右緣之間
4. 敵人（id 遞增）：狀態推進 → AI 決策（§5.9）→ 移動；被摔出的敵人撞人、撞物（§5.17–§5.18）
5. 判定：所有「判定中」的攻擊框對目標（玩家先、敵人依 id）；格擋／卸勁／閃避在這裡結算（§5.3–§5.5）
6. 架勢、破防、處決、死亡結算；掉落、修為、技巧分
7. 冷卻、體力、架勢回復、無敵、反擊窗口遞減
8. 卷軸：補給拾取、戰區觸發與解鎖、鏡頭前進（§5.19）；關尾觸發劍塚與選路（§8）
9. tick++；tick >= MATCH_TICKS → over
```

## §5 規則與事件

### 5.0 對戰架構 v3（招式時間軸、物理、判定形狀）

完整說明在 [gdd/12](12_combat_architecture.md)；本節只列 sim 要對帳的常數與規則。

**招式時間軸**：每招 = 起手／判定／收招 tick ＋ `track`（起手前段可轉向，之後承諾）＋ `lunge`（根位移關鍵點）＋ `hits`（判定關鍵格：形狀、角度、傷害、架勢、力道、group）＋ `armor`（霸體區間）＋ `iframe` ＋ `cancel`（閃避／連段／招式各自從第幾 tick 起可取消）。判定與 render 姿勢讀同一份資料。

**判定形狀（v5）**：清版類的判定是「同一條線上、面前一段距離」。每個判定是 x 方向的區段（從身體前緣往面向延伸 `len` 像素；`back` 標記的往後也延伸，如回身斬）加上深度厚度：目標腳底與攻擊者的深度差 |Δy| ≤ `DEPTH_HIT` ＋ 目標身體半徑 ÷ 2 才算在線上；高度上只打 `z` 在 [`zLo`, `zHi`] 之間的目標（地面招預設 0–`HIT_Z`，對空招往上延伸，低掃只打 z = 0）。v4 的扇形、圓、膠囊換成這個形狀；同一招同一 group 對同一目標只中一次。

| 常數 | 值 | 說明 |
|---|---|---|
| `DEPTH_HIT` | 10 | 深度判定厚度（像素），再加目標身體半徑的一半 |
| `HIT_Z` | 24 | 地面招打得到的最高離地高度（像素）；跳到這個高度以上就跳過地面招 |

| 常數 | 值 | 說明 |
|---|---|---|
| `FRICTION` | 200 | 速度每 tick 乘 200/256 |
| `KNOCK_SCALE` | 16 | 擊退初速（子像素／tick）= 力道 × 16 ÷ 質量 |
| `SLAM_SPEED` | 768 | 擊退中撞到不可破壞的障礙物、深度帶邊緣或鎖定中的鏡頭邊緣時速度超過 3 像素／tick = 撞壁 |
| `SLAM_DMG` | 10 | 撞壁傷害（另加硬直 `SLAM_STUN` = 45） |
| `SEPARATE_PCT` | 50 | 身體重疊時每 tick 推開重疊量的 50%，依質量分配 |
| `CLASH_PUSH` | 120 | 拼刀：雙方都是白光判定且同 tick 互相重疊 → 各自被推開的力道 |
| `CLASH_POSTURE` | 10 | 拼刀雙方各加的架勢 |
| — | — | 背擊（v5）：攻擊者在目標面向的反側（目標面右、攻擊者在它左邊）就算背擊；v4 的 `BACK_ARC` 拿掉 |
| `GRAVITY` | 48 | 浮空時 vz 每 tick 減少量（子像素） |
| `LAND_STUN` | 20 | 浮空落地硬直 |
| `DASH_STRIKE_WIN` | 8 | 閃避結束後 8 tick 內按攻擊 = 回身斬 |

**身體**（半徑像素／質量／韌性）：玩家 6／2／—（玩家吃任何白光以上的命中都會硬直，除非霸體）；屍兵、蠱師 6／1／40；蠱蟲 4／1／10；屍傀力士 9／3／120；精英 10／4／150；頭目 12／8／不會被單擊打斷（只會被斷招與破防打斷）。

**韌性**：命中的力道 ≥ 目標韌性 → 目標硬直並中斷出招（霸體區間除外）；小於則只吃傷害與架勢。

**取消窗**：收招中，從招式的 `cancel.dodge` tick 起可以用閃避取消；普攻從 `cancel.combo` 起可以接下一段；招式從 `cancel.skill` 起可以接招式。取消時緩衝中的動作立刻執行。

### 5.1 移動、深度軸與卷軸

| 常數 | 值 | 說明 |
|---|---|---|
| `MOVE_SPD` | 384 | 子像素／tick（1.5 像素）；深度方向減半（清版類慣例：上下走比左右慢），斜向用查表 `DX/DY` 後深度分量再減半 |
| `DEPTH` | 96 | 深度帶寬（像素）；`y` 夾在 [0, `DEPTH`] |
| `FLOOR_TOP` | 150 | 地面帶在畫面上的頂端（遊戲像素） |

### 5.7 傷害與架勢

```
傷害 = 招式傷害 × (100 + 鍛造等級 × FORGE_DMG_PCT + 技能節點加成) / 100 × (100 − 護具減傷) / 100   （整數，無條件捨去）
架勢 = 招式架勢 × (繞背 ? BACK_POSTURE_PCT : 100) / 100 × (反擊窗口 ? 200 : 100) / 100
```

| 常數 | 值 | 說明 |
|---|---|---|
| `FORGE_DMG_PCT` | 10 | 每級鍛造 +10% 傷害（最高 +3） |
| `BACK_POSTURE_PCT` | 200 | 從目標面向的背後（`BACK_ARC`，約 120°）命中 |

| `EXEC_PCT` | 40 | 處決傷害 = 目標最大氣血的 40%（小兵直接倒）；鎮魄加成另計 |
| `HP_BASE` | 100 | 玩家初始氣血 |
| `STA_MAX` `STA_REGEN` `STA_DELAY` | 1000／6／30 | 體力 |

### 5.9 敵人 AI（固定規則，不擲骰）

1. **進場**：戰區鎖定時，該戰區的敵人依 `enter` stream 的側與延遲，從鏡頭左或右緣外走進來；精英與頭目從右側固定位置進場。
2. **對位**：先把深度對到玩家同一條線（|Δy| ≤ `DEPTH_HIT`），再橫向靠近到招式距離，站在自己目前所在的那一側；那個位置在障礙物裡或在鎖定畫面外時，改站玩家另一側（不會隔著障礙物或貼著畫面邊緣對峙）。路上有障礙物時沿著它上緣或下緣繞過去（2026-11-26 N5：修掉敵人與玩家隔著障礙物、或一起被擠在畫面邊緣而互相等待到時間用完的情形）。
3. **出招**：進入招式距離後，依 `combo` stream 排好的第 *k* 輪順序出招；兩招之間間隔 `FOE_GAP` = 36 tick（精英 28、頭目 20）。
4. **同時進攻上限**：同一時間最多 `MAX_ATTACKERS` = 2 個敵人在起手或判定中；其他人保持 `WAIT_GAP` = 64 像素以外，在深度方向錯開等待（依 id 順序讓位）。同一側同時最多 1 個進攻。金光讀條同時最多一個（v4），確保「斷」永遠有解。
5. **反應規則**：被斷招 → 本輪剩下的招改從下一輪開始；玩家跑到背後 → 每 `FOE_TURN` = 12 tick 才能轉身一次；破防、被抓、被摔出中不能出招。
6. **頭目換招表**：氣血 ≤ 50% 時切換，切換時有 60 tick 的無敵演出（所有人一樣）。
7. **對空**：精英與頭目看到玩家起跳且在招式距離內，優先出 `antiAir` 招（白光，可以不跳來避開）。
8. v4 的巡邏、發現距離、追擊範圍（`PATROL_PERIOD`、`AGGRO_R`、`LEASH_R`）拿掉：戰區內的敵人一進場就進攻，不會回位。

### 5.10 面向與目標（取代 v4 的鎖定）

- 面向只有左右。有水平輸入就轉向；只有上下輸入時面向不變。
- 出招打的是判定範圍內所有在線上的敵人（§5.0），不需要鎖定；v4 的 `LOCK_R` 與 `ACT_RETARGET` 拿掉。
- 招式的自動轉向（`track`）：起手前段若面前沒有敵人、背後有，轉身一次。

### 5.13 劍塚與倒下（v5 精簡）

1. **劍塚在每一關開頭**（第一關在起點）。走到劍塚按 `ACT_INTERACT`：氣血、體力、內力回滿、冷卻清空，進入 §8 面板（升級、配點、換招、換武器與護具、鍛造）。面板開啟時 sim 不走。
2. **倒下**：氣血 ≤ 0 → `DOWN` 60 tick → 回到本關開頭的劍塚，氣血、體力、內力回滿；**整關重來**：本關所有戰區（含已清掉的）的敵人回到配置（同種類、同進場側與延遲），鏡頭回到關卡起點。打破的破壞物不會復原，已撿的補給不會再出現。（2026-11-26 N4 調校：只重來目前戰區時，一路普攻的簡單策略靠倒下也能推進，分數達強策略的 55%；整關重來後降到 13%，也更接近魂系「回到營火、敵人復活」的代價。）
3. 修為、裝備、等級都保留；v4 的遺骸、`CORPSE_AT`、休息時小兵重生都拿掉（休息不會讓敵人復活，只有倒下會）。
4. 倒下不扣分；代價是時間與重打這一關。

- 每關開頭有一座劍塚（休息與倒下的回歸點），頭目關的劍塚在頭目門外。
- 難度只升不降：難度級沿路線單調不減，每關只加一件新東西（光色、敵種或機制）。
- 各關的戰區觸發點、配置點、障礙物與破壞物位置寫在 sim 的 `STAGES`（N4），由 `CHAPTER_SEED` 產生後寫死；本節是唯一的關卡清單。
- 地面帶以外的背景（遠景、中景、前景遮擋）只給畫面，不影響判定。

### 5.16 跳躍與空中攻擊

| 常數 | 值 | 說明 |
|---|---|---|
| `JUMP_VZ` | 1024 | 起跳垂直速度（子像素／tick）；配合 `GRAVITY` = 48，最高約 43 像素、滯空約 43 tick |
| `JUMP_STA` | 120 | 跳躍消耗體力 |
| `JUMP_LAND` | 6 | 落地硬直（空中攻擊落地另加 4） |

- 起跳後水平速度固定為起跳當下的移動方向 × `MOVE_SPD`，空中不能轉向、不能格擋、不能閃避、不能放招式。
- 空中攻擊（每跳一次）：跳斬，判定在身前、從地面到身高，傷害 10、架勢 10、力道 100；打到地面的小兵會擊倒（`CONTROL_TICKS`）。
- 跳躍沒有無敵幀；**跳過** = 身體 `z` 高於該招的 `zHi`。低掃類的赤光（`low` 標記，例如屍傀力士的掃地）可以用跳躍或閃避躲；對空招（`antiAir`）專打跳起來的人。
- 平衡：跳斬落地有硬直，精英與頭目看到玩家起跳會出對空招（§5.9 第 7 條），所以一直跳不是正解（§9 的 `jumper` 策略專門驗這點）。

### 5.17 抓投

| 常數 | 值 | 說明 |
|---|---|---|
| `GRAB_PUSH` | 10 | 貼身（身體邊緣距離 ≤ 4 像素、在線上）朝敵人推方向連續 10 tick → 抓住 |
| `GRAB_TICKS` | 90 | 最多抓這麼久，時間到敵人掙脫（雙方各退 16 像素） |
| `GRAB_HITS` | 3 | 抓著時按攻擊 = 膝撞，最多 3 下（傷害 6、架勢 12） |
| `THROW_FORCE` | 260 | 抓著時推方向＋按攻擊 = 往那個方向摔（推反方向就是過肩摔）。被摔的敵人變成飛行物 |
| `THROW_DMG` | 15 | 被摔者落地傷害；飛行途中撞到的其他敵人也吃 15 並被擊倒 |

- 只能抓質量 ≤ 1 的小兵（屍兵、蠱師、蠱蟲）；屍傀力士、精英、頭目抓不住，貼身推只會被擋住。
- 起手或判定中的敵人抓不住（不能用抓取取消敵人的招）；破防中的小兵可以抓。
- 抓人時玩家沒有無敵，其他敵人照常可以打；被打中就放手。
- 被摔出的敵人撞到可破壞物 → 打破；撞到不可破壞的障礙物 → 撞壁（`SLAM_DMG`）。

### 5.18 障礙物與破壞物

| 種類 | 可破壞 | 耐久 | 尺寸（寬 × 深，像素） | 打破掉落 |
|---|---|---|---|---|
| 酒罈 | ✓ | 10 | 12 × 8 | 肉包（氣血 +30） |
| 木箱 | ✓ | 20 | 20 × 12 | 丹藥（內力 +30）或鍛材 1（每個木箱在關卡資料裡寫死是哪一種） |
| 石燈 | ✗ | — | 12 × 10 | — |
| 斷碑 | ✗ | — | 24 × 14 | — |

- 障礙物擋身體（玩家與敵人都要繞）；攻擊判定不受障礙物阻擋（清版類慣例，避免卡位）。被擊飛或摔出、落在障礙物範圍內的身體可以自己走出來。
- 破壞物被攻擊命中、被摔出的敵人撞到、或被擊退中的身體撞到時扣耐久。
- **不得有一定會扣血的佈置**：同一個 x 位置上，不可破壞障礙物佔的深度合計 ≤ `DEPTH` 的一半，而且至少留一條寬度 ≥ 玩家身體直徑 ＋ 8 像素的通道；戰區鎖定的範圍內同時最多 2 個不可破壞障礙物（測試見 §12）。
- 補給落地後留在原地直到被撿；走過去自動撿。氣血、內力已滿時不撿。

### 5.19 卷軸與戰區鎖定

| 常數 | 值 | 說明 |
|---|---|---|
| `WAVE_LOCK` | 480 | 戰區鎖定時，鏡頭停在觸發點，玩家只能在這 480 像素（一個畫面）內活動 |
| `GO_DELAY` | 30 | 戰區清空後過 30 tick 解鎖，畫面提示往右 |

- 玩家走到戰區觸發點 → 鏡頭鎖定、該戰區敵人依 §5.9 進場；全部倒下 → 解鎖。
- 精英與頭目關是單一戰區，整個關卡寬度就是戰場。
- 鎖定中的鏡頭左右緣算牆（撞壁成立）；沒鎖定時敵人被擊退最遠到鏡頭外 `EDGE_PAD` × 4。

## §6 計分

| 項目 | 公式 | 上限 | 技巧意義 |
|---|---|---|---|
| 頭目 | 中頭目各 `BOSS_PTS` = 2000，終頭目 `FINAL_PTS` = 5000 | 共 9000 | 打得過 |
| 剩餘時間 | 終頭目倒下時：剩餘秒數 × `TIME_PTS` = 10 | 4200 | 路線與練等的取捨 |
| 卸勁 | `PARRY_PTS` = 30 × 修為遞減比例 | `TECH_CAP` = 60 次 | 時機 |
| 完美閃避 | `PERFECT_PTS` = 30 × 同上 | 60 次 | 時機 |
| 斷招 | `INTERRUPT_PTS` = 60 × 同上 | 30 次 | 反應 |
| 處決 | `EXEC_PTS` = 80（小兵 20）× 同上 | 30 次 | 架勢經營 |

- 技巧分對**同一配置點**的敵人套用 `XP_DECAY_PCT`：重生小兵刷技巧分會越來越少，第 4 次以後為 0；頭目與精英只計一次生命。
- 理論最高分 = 9000 + 4200（7 分鐘內不可能為 0 秒用時，實際更低）+ 60×30 + 60×30 + 30×60 + 30×80 = **21,000**；上傳分數超過即異常。
- 「只是活著」沒有分：沒有存活秒數分；時間分只在終頭目倒下時給。
- 結算逐項列出（`scoreBreakdown()`）：頭目、時間、卸勁、完美閃避、斷招、處決，以及倒下次數（只顯示不扣分）。

## §9 比較策略（技巧證據）

| 名稱 | 角色 | 能看到什麼（不得多於真人） | 能力限制 / 怎麼選動作 |
|---|---|---|---|
| `expert` | strong | 視窗內的敵人位置、面向、起手光色與讀條、自己的資源與冷卻、關卡資料 | 依光色選正解；卸勁與完美閃避照人性化模型的「熟手」時機誤差（σ 約 20 ms、反應 200 ms）；錯開深度避免包夾、繞到背後；低掃用跳躍躲；抓小兵摔向人群；氣血低時打破酒罈補血；選蠱林；固定配點 |
| `random` | random | — | 每 tick 依 `hash32(seed, 'rnd', tick)` 選方向與動作碼 0–10；排除 `ACT_INTERACT` 以外的劍塚操作（劍塚面板一律選 0 離開）；用意是「完全不讀局面」 |
| `masher` | simple | 最近的敵人 | 對齊最近敵人的深度、走過去，一直普攻；冷卻好了就放招式 1 |
| `blocker` | simple | 敵人有沒有在起手（不看光色） | 見起手就格擋，其餘普攻 |
| `dodger` | simple | 敵人有沒有在起手（不看光色） | 見起手就閃避，其餘普攻 |
| `jumper` | simple | 最近的敵人 | 清版類的老招：對齊深度後一直跳斬（落地就再跳） |
| `grabber` | simple | 最近的敵人 | 貼身抓小兵、膝撞三下再摔；抓不住的敵人就普攻 |

v4 的 `grinder`（回劍塚刷修為）拿掉：v5 沒有小兵重生，無法刷。

規則：只送出真人能送的 byte；亂數用 `hash32(seed, salt, 事件序號)`；同一題每次結果相同。確認用題目跑過之前凍結。
