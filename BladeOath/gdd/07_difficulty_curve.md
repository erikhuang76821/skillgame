# 07 難度曲線

> 方法：[16_difficulty-curve](../../knowledge-base/16_difficulty-curve.md)（腳本化、上升鋸齒、人性化試玩、D1–D8）；門檻只在 `knowledge-base/index/rules.json`（`RULE-CURVE-*`）。報告：[docs/playtest_report.md](../docs/playtest_report.md)（`npm run playtest`）。
> 範圍：sim v5（橫向卷軸清版；劍流派；山門 → 蠱林／枯井 → 屍傀將殿 → 殿後迴廊 → 墮仙台，gdd/05 §5.14）。試玩 bot 走蠱林路線；枯井只在技巧證據與單元測試裡走到。

## 1. 單位、DI 與命中率（本品類的定義）

| 項目 | 定義 | 為什麼 |
|---|---|---|
| 單位 | 一個戰區：鏡頭鎖定後一起進場的那一批敵人（`tools/units.mjs` 的 `UNITS`，依路線順序） | 清版類的「一波」（[16 §2.1](../../knowledge-base/16_difficulty-curve.md)） |
| 目標 | 一次威脅到玩家的敵招（起手時玩家在它的線上、攻擊距離＋位移＋餘裕內） | 讀招對決的基本單位 |
| 命中率 | 這些敵招中，玩家沒有被打實的比例（卸勁、格擋、閃避、跳過、走出線外都算） | 對應節奏類的「打中音符」 |
| DI | Σ 敵人（氣血 / 30）×（招式光色權重平均：白 1、金 1.5、赤 2），種子平均 | 越耐打、越需要讀光色的敵人越難 |
| 主段落 | 山門、蠱林、殿後迴廊 | 精英與頭目每場只有一個目標，另外報告（同 SkyTalon） |

## 2. 難度級（每級只加一件事）

| 級 | 段落 | 新加的一件事 | 敵人（每波） |
|---|---|---|---|
| 1 | 山門 | 白光起手（學格擋與卸勁）、深度軸對位、卷軸鎖定 | 屍兵＋蠱蟲 → 屍兵＋蠱蟲 ×2 → 屍兵 ×2＋蠱蟲 → 屍兵 ×3＋蠱蟲 |
| 2 | 蠱林 | 金光讀條（學斷招） | 屍兵 ×2＋蠱師 → 屍兵＋蠱師 ×2 → 屍兵 ×2＋蠱師 ×2 |
| 3 | 蠱母（精英） | 白＋金＋赤的單一強敵、對空招、會脫離 | 蠱母 |
| 4 | 屍傀將（中頭目） | 頭目節奏（間隔 20 tick）、對空招、會脫離 | 屍傀將 |
| 5 | 殿後迴廊 | 赤光霸體與低掃（學閃避與跳躍）；第一隻屍傀力士單獨出現 | 屍傀力士 → 力士＋蠱師＋屍兵（兩波）→ 力士 ×2＋蠱師 |
| 6 | 墮仙（終頭目） | 三色混用、半血換招表（多段招、大範圍低掃） | 墮仙 |

種子只決定同一戰區內「哪種敵人站哪個深度、從哪一側進場、晚幾 tick」與出招順序；關卡、戰區與難度級是固定腳本。

## 3. 容錯參數

| 參數 | 值（sim 常數） | 作用 |
|---|---|---|
| 卸勁窗口 | `PARRY_WIN` = 8 tick（技能 +2） | 時機技巧的寬度 |
| 完美閃避窗口 | `PERFECT_DODGE_WIN` = 6 tick；無敵幀 12 tick | 閃避本身寬容，壓線才給分 |
| 線的厚度 | `DEPTH_HIT` = 10 像素＋目標半徑一半 | 上下錯開就打不到：清版類最基本的閃避 |
| 控場上限 | `CONTROL_CAP` = 90 tick，之後無敵 30 tick | 不會被連到死 |
| 起手下限 | 白 18、金 60、赤 24 tick | 都比一般玩家反應時間（15 tick）長 |
| 同時進攻 | `MAX_ATTACKERS` = 2，同一側最多 1 個 | 被包夾時一定一左一右，往上下閃就能離開 |
| 倒下 | 回本關劍塚、整關重來 | 代價是時間，不是分數 |

## 6. 已知弱點（N9 真人試玩要看）

1. **新手打倒終頭目只有 40%**：整關重來讓倒下的代價變大。N9 看真人倒下幾次、在哪一關放棄；太挫折時可以考慮頭目關前多一座劍塚，不改門檻。
2. **一般玩家有 7% 打不完**（v5-1 的 23% 多半是對峙卡死，v5-2 已修）。剩下的卡在墮仙第二階段；若真人也一樣，考慮降低第二階段的赤光比例。
3. **masher 仍有幾題打倒屍傀將**：它的疾刺偶爾正好斷到金光讀條，接著處決。分數比 13%，在可接受範圍，確認批跑完後由人判定接近程度。
4. **跳躍與抓投在試玩 bot 裡用得少**：人性化 bot 繼承強策略，只在低掃時跳、只抓格擋中的小兵；真人可能更常用，N9 要看。
5. **迴廊一般玩家 93%**，離 90% 下限還有餘裕；第 7 單位（蠱林第三波）91% 是最低點。
6. 命中率模型只量「有沒有被打實」，沒有量卸勁比例；卸勁率的曲線在 N9 用真人資料補。
