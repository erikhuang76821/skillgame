# 試玩紀錄（N9）

## 怎麼收

1. 在 `BladeOath/game` 執行 `npm run dev -- --host`，請試玩者開 `http://<這台電腦的位址>:<埠>/?playtest=1&tester=<代號>`（代號用英數或中文，不要用真實姓名）。自己玩就開 `http://localhost:<埠>/?playtest=1&tester=<代號>`。
2. 不要先講解規則，讓他看開始畫面自己玩。一局最長 7 分鐘，至少玩 2 局，結算面板按「再來一局」繼續。
3. 玩完在結算面板按「匯出試玩紀錄（N 局）」，會下載 `bladeoath-playtest-<代號>-<日期>.json`。
4. 把檔案放進這個資料夾的根目錄。

紀錄只存在試玩者的裝置上（同一個代號在同一個瀏覽器會累積），遊戲不連線、不上傳。每一筆是一局的種子、輸入紀錄、選擇與分數，加上代號、時間與螢幕尺寸；沒有其他個人資料。

## 怎麼看

在 `BladeOath/game` 執行：

```
npm run human-report
```

報告寫到 `BladeOath/docs/human_playtest_report.md`：每一局先重播驗分，再逐段和模擬玩家（`game/tools/humanBots.mjs`）對照命中率、倒下次數、第一次倒下的時間點、走到哪裡。

## 試玩時順便記下來的事（報告量不到）

- 看完開始畫面，知不知道要做什麼、分數怎麼來。
- 白、金、赤三種起手光，第一次看到時懂不懂該卸勁、閃避還是斷招。
- 被打中時知不知道是被哪一招打中的。
- 劍塚（休息點）找不找得到、知不知道點亮後倒下會回到這裡。
- 覺得太簡單還是太難，在哪一段（山門、蠱林、蠱母、屍傀將、殿後迴廊、墮仙）。
- 觸控：按鈕位置會不會遮住角色或敵人。
